## Quick note
**This mod does not work after ULTRA_REVAMP update.**

If you wanna play it you gotta downgrade. There's plenty of guides out there that will help you do it you just gotta apply some brain power into it.

Current codebase consists of sticks and stones that break my bones. It's pending a full rewrite for better scalability because looking at it now, my eyes start to water and I want to puke.

If you wanna take a look at it - [there it is](https://github.com/whateverusername0/VRTRAKILL/compare/stable...ultra_revamp) (or just check the ultra_revamp branch on this repo).

If you really want to run it on the latest version I suggest looking up [forks](https://github.com/whateverusername0/VRTRAKILL/forks) of the mod. Maybe some enthusiast managed to run it on REVAMP with the current stenching codebase.
